# SaarthiX multilingual guide

Languages: English, हिन्दी, বাংলা, मराठी, தமிழ், తెలుగు, ગુજરાતી, ಕನ್ನಡ, മലയാളം, ਪੰਜਾਬੀ

## How it works
- `src/i18n/languages.ts`  - language list, browser-language detection, Google Fonts URL
- `src/i18n/locales/en.ts` - English = source of truth (all keys live here)
- `src/i18n/locales/<code>.ts` - one file per language; missing keys fall back to English
- `src/i18n/index.tsx` - `I18nProvider`, `useT()`, `useI18n()`
- `src/components/language-switcher.tsx` - the globe dropdown (public header + workspace header)
- `src/styles.css` (bottom) - Noto Sans font per script + taller line-height

The choice is saved in `localStorage` (`saarthix:lang`). First visit uses the browser language.

## Translating another page (3 steps)
1. Add the key to `en.ts`:      `"patientDash.title": "Your health at a glance",`
2. Add it to each `locales/*.ts` (skip a language and it just shows English)
3. In the component:
```tsx
import { useT } from "@/i18n";
const t = useT();
<h1>{t("patientDash.title")}</h1>
<p>{t("common.notificationsUnread", { n: 3 })}</p>   // "{n}" placeholders
```
